# Cortex Institutional Quant Platform

A high-grade, deterministic-first, regime-aware multi-strategy trading laboratory.

## Technical Architecture

- **Regime-Routed Strategy Engine**: Signals are generated by specialized modules (Breakout, Gap, Mean Reversion) matched to current market state.
- **Hierarchical Validation Pipeline**:
    1. **Deterministic Logic**: Setup matching using technical features (Hurst, ADX, Volatility).
    2. **Asset-Aware Risk Gating**: Kelly-Criterion sizing scaled by regime stability and asset profile.
    3. **ML Meta-Labeling**: Secondary probability filter to reduce false positives.
    4. **Execution Selection**: RL-optimized timing and slippage management.

## Key Upgrades

- **Realistic Backtesting**: Session-aware liquidity, regime-scaled slippage, overnight costs, and structured attribution.
- **Drift Monitoring**: Real-time tracking of feature importance decay and signal latency.
- **Structured Logging**: Versioned JSON events for regime shifts, fills, and attribution analysis.

## Core Modules

- `src/strategies/`: Specialized strategy families (Breakout, Pullback, MR, Range, Gap).
- `src/regime/`: State detection using Hurst exponent and time-series persistence.
- `src/portfolio/`: Meta-labeled orchestrator for signal ranking and conflict resolution.
- `src/risk/`: Asset-aware sizing engine with crash protection.
- `src/rl/`: Execution agents for active trade management.

## Pipeline Architecture

`Market Data` → `Regime Classification` → `Strategy Signals` → `Meta-Model (ML Filter)` → `Risk Gating` → `Execution Timing` → `Post-Trade Attribution`
